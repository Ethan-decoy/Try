## 开始练习

Windows 单文件版放在可写的文件夹中，双击 `try.exe` 打开主窗口。右下角从左到右是「回到托盘」、最大化／还原和「退出 Try」。点「回到托盘」可让定时提醒继续运行，点电源图标会退出程序。也可以从托盘菜单选择「退出」。题目或知识包资料有未保存的修改时，返回托盘、退出或开始练习前可选择继续编辑、保存并继续或放弃修改。

Windows 版主窗口和图片预览的细边框随 Try 的外观切换。拖动顶部空白处移动窗口，双击可最大化或还原，拖动边缘或四角可调整大小。图片预览也可以按 Esc 关闭。

在 Windows 和 Linux 上，左键点击托盘图标开始一题。macOS 从菜单栏的 Try 图标选择「练习」。托盘右键菜单和菜单栏菜单还提供打开、设置、暂离、暂停／恢复、关于和退出。

填空按 Enter 核对，选择题点击选项或按 1、2、3，判断题点击 ✓ / ✕ 或按 1、2。答对时卡片变绿。答错时卡片变红，填空题在原输入位置显示标准答案，下方保留你的作答。选择题和判断题在原处框出正确项。错题可按 Enter 或点击卡片右下角的收起图标。未作答或答对时可按 Esc 收起，答对后也可按 Enter 提前收起。未提交的题目不计入作答记录。

右键练习卡片可打开快捷菜单，也可在卡片取得焦点后按菜单键或 Shift+F10。「不再练习此题」取消当前题目的参与勾选并收起卡片，保留内容与学习记录，可在知识包中重新勾选；「暂离」提供 1、2、3 小时及自定时长；「记录此题问题」将本题、标准答案、本次输入与公式、判定结果及版本信息自动保存为当前数据目录下 `bug_reports/` 中的一份 JSON，菜单显示「已在本地记录」。记录不联网，不需要填写说明；同一版本的相同现场复用同一文件，保存失败可重试。记录不会更改题目或作答结果，未完成、尚未提交的公式也可记录。答题和知识展示均可使用菜单；菜单展开期间暂停自动收起，关闭后继续剩余时间，Esc 只关闭菜单。

「设置 → 卡片 → 卡片位置」提供屏幕工作区的四个角点。拖动题面或空白处移动卡片后，Try 会保存为「自定义位置」，可在同一菜单中选任一角点切回。开启「锁定卡片」后，拖动和缩放手势都会停用。也可从卡片右键菜单的「暂离」下方锁定或解锁当前卡片，设置会同步保存。

在 Windows 上，未锁定时可拖动卡片边缘或四角调整大小，最小为 320 × 288 逻辑像素。松开后会记住尺寸，答题和展示共用，重启后也会保留。「恢复自动尺寸」让卡片重新根据题目内容调整高度。

内容超出卡片时，可用 Page Up / Page Down 翻页。在展示、选择、判断和反馈状态下，也可按 ↑ / ↓ 滚动，或用 Home / End 跳到首尾。

定时答题卡片出现后默认可以直接输入，选择和判断也可直接用数字键。玩游戏或不想被打断时，在设置「卡片」中关闭「弹出时自动聚焦」：完整题板保持显示，出现和悬停都不自动取得焦点；释放鼠标后主动点击题板即可作答，也可从系统托盘进入。Windows 在其他窗口隐藏光标或捕获鼠标时让题板鼠标穿透，释放后恢复点击；切回游戏后继续保留题板。未激活的题板不开始记录本次练习。开关重启后保留；知识展示不自动接管键盘。

Windows 在每次定时提醒前检查系统通知状态。关闭自动聚焦后允许在无边框全屏等忙碌场景显示题板；系统报告独占 Direct3D 全屏、演示或锁屏时仍延后，不补弹积压提醒。自动聚焦开启时也会避开系统忙碌状态，从托盘手动开始不受限制。Try 不识别游戏内的 Esc 或暂停菜单，鼠标保护依赖系统报告的光标与捕获状态；自行绘制光标或使用其他输入方式的游戏仍需实测。macOS/Linux 目前保留点击后作答，但尚未接入这套游戏鼠标保护和全屏查询，桌面交互仍需验收。

答对后的反馈与知识展示分别使用各自的停留时间，从答对后或展示答案时开始计时。答错不使用停留计时，未作答的题目也会保持打开。主窗口打开时暂停自动弹题，回到托盘并结束练习后重新等待完整提醒间隔。

在主窗口底部点击「答题」或「展示」即可切换练习方式。用 Tab 移到切换控件后，可按左右方向键选择。手动练习从系统托盘进入，定时提醒沿用所选方式。知识卡按「知识展示停留」自动收起，Enter 或 Esc 也可收起。

也可在系统托盘右键／菜单栏菜单中直接切换：展开「练习方式 · 当前方式」，选择「答题」或「知识展示」，✓ 表示已选方式。切换会自动保存并同步主窗口；已打开的题板保持当前方式，下一题使用新选择。

答题先覆盖当前参与练习、当前题型下没有作答记录的题目。每题有效作答一次即完成首轮，不要求首次答对；只看过或收起未作答题不会算完成。未作答题之间轮换，优先展示尚未出现的题目；新增题目、重新启用的未作答题，以及切换到尚未作答的题型，也优先完成首轮。

当前参与题目均有作答记录后，再根据正确／错误与实际经过时间调整出现机会。错题会在穿插其他题后获得更多回访，旧题保留轮换；所有题都熟悉时仍按当前提醒节奏安排维护。填空、选择和判断分别保存个人状态。只看知识点沿用普通选题，不读取或更新学习记录；切回答题继续使用原记录。

## 知识包与题目

已设置的标签会同时显示在左侧包名前。侧栏与练习卡片共用「显示知识包标签」开关，长标签省略显示，悬停可查看完整文字。

知识包标题旁的「⋯」菜单可以编辑一个短标签，例如「公式」或「英语」；标签和名称搭配合适即可，例如「公式 · 微积分」「英语 · 单词」，避免重复相同信息。Enter 保存、Esc 取消，留空则不显示。标签随知识包导出。练习卡片靠屏幕左侧时标签在右上角，靠右侧时在左上角，拖动后自动换边。设置页「卡片」中的「显示知识包标签」可以统一隐藏，重启后保留选择；已有知识包没有标签时仍保持原样，可自行填写。

Try 练习的是看到提示就想到答案的对应关系，尽可能省去临时推导。选择自己感兴趣、希望熟悉的知识，再拆成每次能简短回答的一题。

标题下方的「介绍」可展开或收起。收起时显示首行摘要，展开后查看完整的内容范围与使用约定；较长介绍可在区域内滚动。点击「编辑」修改内容，保存或取消后保持展开；没有介绍时可点「添加」。切换知识包后默认收起，显示新包的摘要。

- 点击侧栏包名查看内容。包名获得焦点后，上下方向键切换相邻知识包，Home 和 End 跳到首尾。每个包右侧的开关只控制该包的参与状态，可以同时开启多个包。关闭再开启保留之前的逐题选择。
- 列表行首复选框控制单题参与，表头最左侧的复选框控制当前包的所有题目。每行题型菜单设置填空、选择或判断，表头「统一题型」批量设置。内容不足的题型呈禁用状态，可进入编辑器补齐。
- 侧栏上方加号新建包，向下箭头导入 JSON。点击知识包右上方的「新增题目」添加题目，空包也有添加入口。包名旁的「⋯」提供改名、标签、介绍、导出与删除。Enter 保存名称，Esc 取消。
- 点击题面进入编辑器。填空编辑题目与答案；选择题编辑题目和三个选项并指定正确项；判断题编辑陈述并指定 ✓ / ✕。保存经过校验后生效，普通取消保留原题。
- 删除单题：在题目行的「⋯」菜单中选择删除，或在已有题目的编辑器中点右上角垃圾桶，再确认。取消删除保留草稿；删除最后一题保留空包，可以继续新增或导入。
- 删除整包：在包标题旁「⋯」菜单中选择删除，再确认。需要备份可先导出；删除最后一包后仍可新建或导入，重启不会恢复已删除的内容。

删除确认在窗口中央显示，默认选中「取消」，Esc 也可取消；确认时显示具体知识包或题目。检测到可用新版后，左下角「关于」图标显示红色小圆点，打开关于页可查看更新。

导入会将完整内容保存到 Try 的本地数据。源 JSON 改名、移动或删除不影响使用；修改外部文件后需重新导入，替换相同 id 时会要求确认。应用内编辑和删除不改写原导入文件。导出包含知识包内容，提醒设置、参与范围和逐题题型属于本机设置。

主窗口底部显示导入和导出的处理状态与结果。操作失败时，可查看原因并重试。替换知识包保存失败时，确认框会保留，方便再次尝试。

向原来只选部分题目的包新增题目时，新题先不参与；原包全选时，新题一起参与。空包暂不参与练习，添加题目后沿用原启用状态。

知识包可承载公式、词汇、快捷键等内容。制作 JSON 时参考 [格式说明](knowledge_pack_format.md) 和 [AI 制作模板](knowledge_pack_ai_template.md)。可直接导入三份进阶模板：[公式 · 微积分](../knowledge_packs/authoring_template.json)、[英语 · 进阶单词](../knowledge_packs/vocabulary_template.json)、[Rust · 常用写法](../knowledge_packs/rust_template.json)，每份 12 题；标签与名称按内容搭配，显示为「标签　名称」。

## 图片题面

每道题可以附一张静态 PNG 或 JPEG 图片。点击「添加图片」选择文件，也可将图片文件拖入正在编辑题目的主窗口。已有图片可以更换或移除，点击预览图可放大查看。保存提交整个题目，取消编辑保留原图片。

练习时沿用紧凑卡片，按短提示、图片、作答区排列。有图片时可将题面文字留空。填空、选择和知识展示只显示图片与作答区或答案，不保留文字占位；主窗口以带序号的「图片题」显示，仍可点击编辑。需要文字提示的图片题照常显示；判断题仍显示判断陈述。没有图片时必须填写题面。

图片保留原色、等比完整显示，支持填空、选择、判断与知识展示；点击图片可在独立窗口中放大，Esc 关闭放大窗口。查看大图时暂停卡片的自动收起，返回后可继续作答或手动收起。错题可点击收起图标或按 Enter。

图片导入后复制到 Try 数据目录的 `media/`，不依赖原文件位置。导入文件上限 8 MiB、1200 万像素，宽高均不超过 8192 像素；软件在后台按卡片需要缩小，显示用图最多 524288 像素。每个知识包最多使用 128 张不同图片、处理后合计 16 MiB。同一图片可以被多题共用，只有不再被任何题目或当前草稿引用时才会清理。

含图知识包仍导出为一个 JSON 文件，图片随包携带；换一台电脑导入也能使用。文字、公式和图片均使用同一知识包格式。移动 Windows 便携版时请保留整个 `data/`，包括 `media/`。图片缺失或损坏会提示修复，不会作为一次错误作答。

## 公式输入

编辑题目时，点击题面、答案或选项，在当前字段标题右侧选择「文本」或「公式」。新字段默认为文本。代码、路径和词汇按原样输入，作答去掉首尾空白后与标准答案或别名逐字匹配。切换到公式再切回文本时，期间没有编辑的内容会恢复原来的写法和空格。

填空题按答案字段保存的格式作答。题面可以设为「公式」，同时把单位 `m/s` 这样的答案设为「文本」。旧题缺少 `answer_latex` 时按文本规则作答。要为旧题启用公式输入和判分，把答案切换为「公式」并保存。

公式答案从第一键开始使用公式编辑器，支持直接输入 `sin(pi/3)`、`sqrt(3)/2` 或粘贴支持的 LaTeX。输入分子后按 `/`，答框立即建立上下分式，光标移到分母。ƒ 可开合下方的键盘。未完成的根号、分数等保留为草稿，提交时会在答框下方提示缺项，必要时将提示滚动到可见区域。

公式题中可直接粘贴 `lnx`、`sinx` 等简写，或输入 `yln(x)`、`ysqrt(x)` 等带系数的表达式，沿用公式编辑器的识别。判分支持省略乘号和不影响含义的括号，例如 `2x`、`2*x` 与 `2*(x)`；函数参数和指数范围仍须正确。

作答框内可以点击分子、分母或指数定位，左右键移动，上下键切换排版行；按住 Shift 配合方向键或点击公式扩展选择，也可拖动选择。公式复制粘贴使用支持的 LaTeX，普通文字保留原文；Ctrl+Z / Ctrl+Y 撤销和重做。识别用于书写和排版，不进行任意代数化简或近似数值判等。

光标在指数或下标内时，`+`、`-` 等运算符继续输入在该位置。要在外层继续输入，先在行末按右方向键，或按空格移出。

ƒ 展开下方公式键盘，支持函数、符号、分数、根号、上下标、积分、求和、极限、矩阵和分段函数。练习作答始终使用同一个输入控件，ƒ 只开合键盘，保留未完成的公式、光标、选区和撤销记录。Enter 直接核对答案；未完成的公式继续提示补齐。键盘展开时 Esc 收起键盘，已收起时 Esc 关闭未作答题板。

公式键盘分为「结构」「符号」。数字、字母与普通运算符直接用实体键盘输入；结构页提供分数、上下标、带底数对数、根式、导数、积分、求和、连乘和极限，符号页按九个分类浏览。数学输入中键入 `log` 即可填写底数，按 Tab 进入真数，与点击对数工具使用相同结构；也可继续使用 `log_2(x)`，或用 `log(x)` 表示不指定底数的写法。`sqrt`、`frac`、`sum`、`int` 和 `lim` 等命令直接建立可填写结构；普通文字答案保留文本输入。

Tab 移到下一个字段，Shift+Tab 返回上一个。例如在 `log²(x)` 的 `x` 处按 Shift+Tab 可回到指数，按 Tab 再回到真数。空格移出当前结构，方向键按排版位置移动。指数和下标内的运算符不会自动移到外层。连续输入 `sqrt(3)/2` 会在右括号处结束根式，再输入外层分母。刚发生自动构造时，Ctrl+Z 先恢复原始命令，Ctrl+Y 重做构造。

悬停查看工具说明；撤销、重做会按编辑记录启用。收起工具区会保留已选范围。练习中通过 ƒ 或 Esc 收起键盘，题目编辑器保留「应用公式」和「取消」。

题目编辑器中的 ƒ 仍用于编辑选中的公式内容；「应用公式」或 Enter 写回该字段，Esc 取消这次修改。普通文字和文字数学混排仍可在内容编辑器中编辑。

展开和收起时，卡片沿用所选角落或手动放置的位置；为避开屏幕边界的临时移动不会覆盖记忆位置。

内容编辑器中的「外移」「拆层」用于调整作用范围并保留内容。公式键盘的「清空」清空当前字段，撤销恢复清空前的草稿和位置；清空不提交答案。结构工具使用当前光标和选区；空模板可退出后再回来填写。

## 设置与暂停

「设置 → 卡片 → 显示操作提示」默认开启。熟悉操作后可以关闭它，隐藏「Enter 核对」、数字键选择、点击激活和「Enter 收起」等提示。隐藏文字时会保留原有的卡片高度和底部留白。快捷键照常可用，公式缺项和错题订正仍会显示。重启后会记住选择。

「设置 → 通用 → 界面动效」默认开启，重启后保留选择。在 Windows 上，用鼠标打开主窗口菜单、精细配置和「关于」时，弹层会在原位淡入。用齿轮打开设置时，正文原位淡入。点击另一分类时，正文会从目标标签所在的一侧轻轻滑入并淡入。切换练习方式时，选中框会滑到新选项。练习卡会轻轻放大出现、缩小收起。答对时，绿色细线先从输入框或所选选项向外散开，随后一圈更淡的细线沿整张卡片的圆角外缘漾开、消失。答错时，一圈淡红色细线从外侧收向卡边并淡去，标准答案或正确选项同时轻轻移入。关闭动效后直接显示最终状态，红绿反馈和 Enter 收起照常可用。Windows 关闭系统动画时，Try 也会关闭这些动效。

点击左下角的齿轮图标进入设置，旁边的「关于」图标用于查看版本与更新。设置分为「练习」「卡片」「通用」，修改后自动保存，失败时保留此前有效数据。「通用」中的「外观」可以选择浅色、深色或跟随系统，默认跟随系统；主窗口内容、标题栏和练习卡片同步变化，重启后保留选择。已有明确保存的浅色／深色选择保持有效。同页「语言」可以选择跟随系统、简体中文或 English，知识包内容保持原语言。

「练习」中分别设置「答对后停留」与「知识展示停留」，两项互不影响。错题会保持打开，直到点击收起图标或按 Enter。提醒间隔提供 15、25、30、45 分钟，答对后停留提供 1、2、3 秒，知识展示停留提供 5、8、15、30 秒。旁边的精细配置图标可输入自定值，两项停留均支持 1 至 60 秒；Enter 应用，Esc 取消。已有用户的两项初始值均沿用原来的卡片停留时间，随后分别保存。

「暂离」按选定时长停止自动弹题；「暂停」持续到手动恢复。暂停状态重启后保留，「恢复」重新等待完整提醒间隔，不补发错过的题目。暂停和免打扰期间仍可手动开始一题，手动练习不会解除暂停。

「答题／展示」的选择会自动保存。普通启动、登录自启和软件更新后均沿用上次的选择。

每日免打扰与登录自启默认关闭。免打扰可跨午夜，默认时段 22:00 至次日 08:00；登录自启开启后直接进入托盘。

## 数据、更新与问题反馈

Windows 发布版首次运行在 exe 旁创建 `data/`，`state.json` 保存设置与知识包，`learning_state.json` 单独保存个人练习状态。已有数据首次更新没有历史时从未评估开始，知识展示不会创建学习文件；导出知识包不包含个人记录。Mac/Linux 默认使用系统应用数据目录，导入后同样不依赖原 JSON 路径。开发构建及独立数据目录参数见 [开发说明](development.md)。

关于页检查已公开的正式版。发现更新后，点击「下载并重启」开始下载，可查看进度或取消；下载与校验完成后自动退出、安装并重启，无需再次确认。开始前先保存或取消正在编辑的内容；下载期间新开的编辑或待确认导入会暂缓重启，保存或取消后自动继续，等待期间仍可取消更新。下载失败或校验不通过不会重启。Try 替换原位置的程序，并使用原数据目录重新启动，设置、知识包、图片和学习记录继续保留。新版完成数据读取与启动后才清理旧程序；替换或启动失败时尝试恢复旧版及配置备份，恢复失败则显示保留备份的位置。

点击下载后会先重新检查最新公开版本，再下载对应程序；本次检查不受每日自动检查间隔限制。检查与下载阶段均可取消，失败时可重试；检查失败不会继续安装此前缓存的旧版本。

兼容支持从 1.0.0 开始。从 0.x 预发布版升级前，请备份完整数据目录。Try 会沿用能读取的旧数据，预发布版的迁移不作保证。搬移便携版时将 exe 与 data 一起移动；开启过登录自启的程序搬移后，可在新位置关闭再开启登录自启，更新系统启动项。

关于入口为左下角 ⓘ，可查看版本、手动检查更新、打开项目主页和第三方声明；Esc 或点击面板外收起。完整版权与许可见 [许可说明](licensing.md)。

默认开启自动检查更新：启动后至少等待 30 秒，每 24 小时最多自动检查一次，重启不会重复检查。有新版时在关于图标显示红点，详情在关于页查看，不另弹通知；只有主动点击「下载并重启」后才开始下载并在完成后重启。设置「通用」中的「自动检查更新」可关闭，手动检查始终可用。检查时间与最近成功结果保存在同一数据目录的 `update_check_state.json`。
