# Try 使用说明

[English](user_guide_en.md) · [返回首页](../README.md)

本说明对应 `0.2.0` 候选版，目标为 Windows x64、macOS arm64 和 Linux x64。平台包与验证范围见 [发布记录](release_checklist.md)。

## 开始练习

Windows 单文件版放在可写的文件夹中，双击 `try.exe` 打开主窗口。关闭主窗口会回到托盘；完全退出请使用托盘菜单的「退出」或主窗口右下角电源图标。

Windows/Linux 左键点击托盘图标开始一题；macOS 点击菜单栏图标，选择「练习」。右键／菜单栏菜单还提供打开、设置、暂离、暂停／恢复、关于和退出。Mac/Linux 是实验性版本，托盘、焦点和文件对话框的完整桌面行为仍待验证。

填空按 Enter 核对答案；选择题点击选项或按数字键 1、2、3；判断题点击 ✓ / ✕。正确时卡片变绿，答错时变红并显示答案。Esc 收起卡片，反馈后 Enter 也可立即收起；未提交不产生作答结果。

定时答题卡片出现后默认可以直接输入，选择和判断也可直接用数字键。在设置末尾关闭「弹出后直接输入」后，卡片出现时保留其他窗口焦点，点击卡片或手动开始再作答。此开关重启后保留；知识展示不自动接管键盘。

卡片停留计时从作答后或展示知识点时开始，未作答的题目会保持打开。主窗口打开时暂停自动弹题，回到托盘并结束练习后重新等待完整提醒间隔。

主窗口左下角 Logo 切换答题与知识展示：白色为答题，描边为只看知识点。知识卡不需要作答，按停留时间自动收起，Enter 或 Esc 也可收起。重新启动默认回到答题模式。

答题根据正确／错误与实际经过时间调整题目出现机会。错题会在穿插其他题后获得更多回访，新题和旧题保留轮换；所有题都熟悉时仍按当前提醒节奏安排维护。填空、选择和判断分别保存个人状态。只看知识点沿用普通选题，不读取或更新学习记录；切回答题继续使用原记录。

## 知识包与题目

已设置的标签会同时显示在左侧包名前。侧栏与练习卡片共用「显示知识包标签」开关，长标签省略显示，悬停可查看完整文字。

展开知识包标题后，可以编辑一个短标签，例如「公式」或「英语」；标签和名称搭配合适即可，例如「公式 · 微积分」「英语 · 单词」，避免重复相同信息。Enter 保存、Esc 取消，留空则不显示。标签随知识包导出。练习卡片靠屏幕左侧时标签在右上角，靠右侧时在左上角，拖动后自动换边。设置页「显示知识包标签」可以统一隐藏，重启后保留选择；已有知识包没有标签时仍保持原样，可自行填写。

Try 练习的是看到提示就想到答案的对应关系，尽可能省去临时推导。选择自己感兴趣、希望熟悉的知识，再拆成每次能简短回答的一题。

- 点击侧栏包名查看内容；旁边的开关决定整包是否参与练习，可以同时开启多个包。关闭再开启保留之前的逐题选择。
- 矩阵行首开关控制单题参与，「全部」行控制当前包的所有题目。填空、选择、判断格子设置题型，「全部」行也可批量设置；内容不足的题型不可选，可进入编辑器补齐。
- 侧栏上方加号新建包，向下箭头导入 JSON，向上箭头导出当前包；悬停图标可查看名称。右侧标题旁加号新增题目，铅笔改包名，箭头展开介绍；Enter 保存名称，Esc 取消。
- 点击题面进入编辑器。填空编辑题目与答案；选择题编辑题目和三个选项并指定正确项；判断题编辑陈述并指定 ✓ / ✕。保存经过校验后生效，普通取消保留原题。
- 删除单题：在已有题目的编辑器中点右上角垃圾桶，再确认。取消删除保留草稿；删除最后一题保留空包，可以继续新增或导入。
- 删除整包：点包标题右侧垃圾桶，再确认。需要备份可先导出；删除最后一包后仍可新建或导入，重启不会恢复已删除的内容。

导入会将完整内容保存到 Try 的本地数据。源 JSON 改名、移动或删除不影响使用；修改外部文件后需重新导入，替换相同 id 时会要求确认。应用内编辑和删除不改写原导入文件。导出包含知识包内容，提醒设置、参与范围和逐题题型属于本机设置。

向原来只选部分题目的包新增题目时，新题先不参与；原包全选时，新题一起参与。空包暂不参与练习，添加题目后沿用原启用状态。

知识包可承载公式、词汇、快捷键等内容。制作 JSON 时参考 [格式说明](knowledge_pack_format.md) 和 [AI 制作模板](knowledge_pack_ai_template.md)。可直接导入三份进阶模板：[公式 · 微积分](../knowledge_packs/authoring_template.json)、[英语 · 进阶单词](../knowledge_packs/vocabulary_template.json)、[Rust · 常用写法](../knowledge_packs/rust_template.json)，每份 12 题；标签与名称按内容搭配，显示为「标签　名称」。

### 入门示例

首次启动附带五个小包，每包四道题；内容是用途示例，可以自行编辑、删除或只开启其中几个。

| 领域与示例文件 | 提示示例 | 答案 |
| --- | --- | --- |
| [数学](../knowledge_packs/math_recall.json) | `(sin x)′ = ?` | `cos(x)` |
| [英语](../knowledge_packs/english_recall.json) | `hesitate` | 犹豫 |
| [编程](../knowledge_packs/programming_recall.json) | Rust：可变引用 | `&mut T` |
| [化学](../knowledge_packs/chemistry_recall.json) | 苯：π 电子数 | `6` |
| [常识](../knowledge_packs/general_recall.json) | `1 海里（米）` | `1852` |

更新软件会保留原有题库与偏好，不自动添加新示例或恢复已删除的内容。已有用户可下载上述 JSON 后导入。题库内容保持作者的原语言，切换界面语言不会翻译题目。

## 图片题面

从 `0.2.0` 起，可以在题目编辑器中添加一张静态 PNG 或 JPEG 图片；`0.1.0` 不包含此功能。点击「添加图片」选择文件，也可将图片文件拖入正在编辑题目的主窗口。已有图片可以更换或移除，点击预览图可放大查看。保存提交整个题目，取消编辑保留原图片。

练习时沿用紧凑卡片，按短提示、图片、作答区排列。图片保留原色、等比完整显示，支持填空、选择、判断与知识展示；点击图片可在独立窗口中放大，Esc 关闭放大窗口。查看大图时暂停卡片的自动收起，返回后可继续作答或按 Enter／Esc 收起。

图片导入后复制到 Try 数据目录的 `media/`，不依赖原文件位置。导入文件上限 8 MiB、1200 万像素，宽高均不超过 8192 像素；软件在后台按卡片需要缩小，显示用图最多 524288 像素。每个知识包最多使用 128 张不同图片、处理后合计 16 MiB。同一图片可以被多题共用，只有不再被任何题目或当前草稿引用时才会清理。

含图知识包仍导出为一个 JSON 文件，图片随包携带；换一台电脑导入也能使用。旧的纯文字／公式 JSON 继续兼容；含图包需要 Try 0.2.0 或更新版本。移动 Windows 便携版时请保留整个 `data/`，包括 `media/`。图片缺失或损坏会提示修复，不会作为一次错误作答。

## 公式输入

常见表达式如 `sin(pi/3)`、`sqrt(3)/2` 和支持的 LaTeX 可以直接输入。完整公式会在输入暂停后排版，普通文字与 `sqrt(` 等未完成草稿保持文本，补齐后重新识别。公式题提交未完成草稿时会提示继续填写。

作答框内可以点击分子、分母或指数定位，左右键移动，上下键切换排版行；Shift 配合方向键或拖动选择。复制和粘贴保留输入原文，Ctrl+Z / Ctrl+Y 撤销和重做。识别用于书写和排版，不进行任意代数化简或近似数值判等。

ƒ 打开公式工具。内容编辑器支持函数、符号、分数、根号、上下标、积分、求和、极限、矩阵、分段函数和文字数学混排；点击预览中的位置编辑参数或单元格。作答面板提供常用结构与数字运算键，✓ 或 Enter 提交，ƒ 收起并应用，Esc 取消面板改动。

「外移」「拆层」用于调整作用范围并保留内容。C 清空当前字段，撤销恢复清空前的草稿和位置；清空不提交答案。结构工具使用当前光标和选区，↑ 选择外层，↗ 在外层后继续输入；空模板可退出后再回来填写。

## 设置与暂停

左下角齿轮进入设置，修改后自动保存，失败时保留此前有效数据。「外观」可以选择浅色、深色或跟随系统，默认跟随系统；主窗口内容、标题栏和练习卡片同步变化，重启后保留选择。已有明确保存的浅色／深色选择保持有效。设置页底部的「语言」可以选择跟随系统、简体中文或 English，知识包内容保持原语言。

提醒间隔提供 15、25、30、45 分钟，反馈停留提供 1、2、3 秒；旁边的精细配置图标可输入自定值，Enter 应用，Esc 取消。已有自定值保留。

「暂离」按选定时长停止自动弹题；「暂停」持续到手动恢复。暂停状态重启后保留，「恢复」重新等待完整提醒间隔，不补发错过的题目。暂停和免打扰期间仍可手动开始一题，手动练习不会解除暂停。

每日免打扰与登录自启默认关闭。免打扰可跨午夜，默认时段 22:00 至次日 08:00；登录自启开启后直接进入托盘。Windows 卡片可选择工作区四角，拖动题面或空白处调整位置。

## 数据、更新与问题反馈

Windows 发布版首次运行在 exe 旁创建 `data/`，`state.json` 保存设置与知识包，`learning_state.json` 单独保存个人练习状态。已有数据首次更新没有历史时从未评估开始，知识展示不会创建学习文件；导出知识包不包含个人记录。Mac/Linux 默认使用系统应用数据目录，导入后同样不依赖原 JSON 路径。开发构建及独立数据目录参数见 [开发说明](development.md)。

更新前从托盘退出，保留 `data/` 并替换 `try.exe`。搬移便携版时将 exe 与 data 一起移动；开启过登录自启的程序搬移后，可在新位置关闭再开启登录自启，更新系统启动项。

关于入口为左下角 ⓘ，可查看版本、手动检查更新、打开项目主页和第三方声明；Esc 或点击面板外收起。完整版权与许可见 [许可说明](licensing.md)。

默认开启自动检查更新：启动后至少等待 30 秒，每 24 小时最多自动检查一次，重启不会重复检查。有新版时只在关于页显示下载入口，不弹窗；设置底部的「自动检查更新」可关闭，手动检查始终可用。检查时间与最近成功结果保存在同一数据目录的 `update_check_state.json`，更新仍需自行下载和替换程序。

问题与建议请提交到 [Issues](https://github.com/Ethan-decoy/Try/issues)。
