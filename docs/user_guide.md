# Try 使用说明

[English](user_guide_en.md) · [返回首页](../README.md)

本说明适用于 Try 0.6.0，支持 Windows x64、macOS arm64 和 Linux x64。已发布下载与平台范围见 [发布记录](release_checklist.md)。

## 开始练习

Windows 单文件版放在可写的文件夹中，双击 `try.exe` 打开主窗口。关闭主窗口会回到托盘；完全退出请使用托盘菜单的「退出」或主窗口右下角电源图标。

Windows/Linux 左键点击托盘图标开始一题；macOS 点击菜单栏图标，选择「练习」。右键／菜单栏菜单还提供打开、设置、暂离、暂停／恢复、关于和退出。Mac/Linux 是实验性版本，托盘、焦点和文件对话框的完整桌面行为仍待验证。

填空按 Enter 核对答案；选择题点击选项或按数字键 1、2、3；判断题点击 ✓ / ✕。正确时卡片变绿；答错时变红并显示标准答案，持续停留，须按 Enter 确认后收起，Esc 不会收起错题。未作答或答对时可按 Esc 收起，答对后也可按 Enter 提前收起；未提交不产生作答结果。

定时答题卡片出现后默认可以直接输入，选择和判断也可直接用数字键。玩游戏或不想被打断时，在设置「卡片」中关闭「弹出时自动聚焦」：完整题板保持显示，出现和悬停都不自动取得焦点；释放鼠标后主动点击题板即可作答，也可从系统托盘进入。Windows 在其他窗口隐藏光标或捕获鼠标时让题板鼠标穿透，释放后恢复点击；切回游戏后继续保留题板。未激活的题板不开始记录本次练习。开关重启后保留；知识展示不自动接管键盘。

Windows 在每次定时提醒前检查系统通知状态。关闭自动聚焦后允许在无边框全屏等忙碌场景显示题板；系统报告独占 Direct3D 全屏、演示或锁屏时仍延后，不补弹积压提醒。自动聚焦开启时也会避开系统忙碌状态，从托盘手动开始不受限制。Try 不识别游戏内的 Esc 或暂停菜单，鼠标保护依赖系统报告的光标与捕获状态；自行绘制光标或使用其他输入方式的游戏仍需实测。macOS/Linux 目前保留点击后作答，但尚未接入这套游戏鼠标保护和全屏查询，桌面交互仍需验收。

答对后的反馈与知识展示分别使用各自的停留时间，从答对后或展示答案时开始计时。答错不使用停留计时，未作答的题目也会保持打开。主窗口打开时暂停自动弹题，回到托盘并结束练习后重新等待完整提醒间隔。

主窗口顶部「练习方式」切换「答题」与「知识展示」。手动练习从系统托盘进入，定时提醒继续沿用所选方式。知识卡不需要作答，按「知识展示停留」自动收起，Enter 或 Esc 也可收起。重新启动默认回到答题模式。

答题根据正确／错误与实际经过时间调整题目出现机会。错题会在穿插其他题后获得更多回访，新题和旧题保留轮换；所有题都熟悉时仍按当前提醒节奏安排维护。填空、选择和判断分别保存个人状态。只看知识点沿用普通选题，不读取或更新学习记录；切回答题继续使用原记录。

## 知识包与题目

已设置的标签会同时显示在左侧包名前。侧栏与练习卡片共用「显示知识包标签」开关，长标签省略显示，悬停可查看完整文字。

知识包标题旁的「⋯」菜单可以编辑一个短标签，例如「公式」或「英语」；标签和名称搭配合适即可，例如「公式 · 微积分」「英语 · 单词」，避免重复相同信息。Enter 保存、Esc 取消，留空则不显示。标签随知识包导出。练习卡片靠屏幕左侧时标签在右上角，靠右侧时在左上角，拖动后自动换边。设置页「卡片」中的「显示知识包标签」可以统一隐藏，重启后保留选择；已有知识包没有标签时仍保持原样，可自行填写。

Try 练习的是看到提示就想到答案的对应关系，尽可能省去临时推导。选择自己感兴趣、希望熟悉的知识，再拆成每次能简短回答的一题。

标题下方的「介绍」可展开或收起。收起时显示首行摘要，展开后查看完整的内容范围与使用约定；较长介绍可在区域内滚动。点击「编辑」修改内容，保存或取消后保持展开；没有介绍时可点「添加」。切换知识包后默认收起，显示新包的摘要。

- 点击侧栏包名查看内容；每个包右侧的独立开关决定是否参与练习，可以同时开启多个包，切换开关不改变正在查看的包。关闭再开启保留之前的逐题选择。
- 列表行首复选框控制单题参与，「全部参与」控制当前包的所有题目。每行题型菜单设置填空、选择或判断，表头「统一题型」批量设置；内容不足的题型不可选，可进入编辑器补齐。
- 侧栏上方加号新建包，向下箭头导入 JSON；内容区的「新增题目」添加题目。知识包标题旁「⋯」菜单提供改名、标签、介绍、导出与删除；Enter 保存名称，Esc 取消。
- 点击题面进入编辑器。填空编辑题目与答案；选择题编辑题目和三个选项并指定正确项；判断题编辑陈述并指定 ✓ / ✕。保存经过校验后生效，普通取消保留原题。
- 删除单题：在题目行的「⋯」菜单中选择删除，或在已有题目的编辑器中点右上角垃圾桶，再确认。取消删除保留草稿；删除最后一题保留空包，可以继续新增或导入。
- 删除整包：在包标题旁「⋯」菜单中选择删除，再确认。需要备份可先导出；删除最后一包后仍可新建或导入，重启不会恢复已删除的内容。

删除确认在窗口中央显示，默认选中「取消」，Esc 也可取消；确认时显示具体知识包或题目。检测到可用新版后，左下角「关于」图标显示红色小圆点，打开关于页可查看更新。

导入会将完整内容保存到 Try 的本地数据。源 JSON 改名、移动或删除不影响使用；修改外部文件后需重新导入，替换相同 id 时会要求确认。应用内编辑和删除不改写原导入文件。导出包含知识包内容，提醒设置、参与范围和逐题题型属于本机设置。

向原来只选部分题目的包新增题目时，新题先不参与；原包全选时，新题一起参与。空包暂不参与练习，添加题目后沿用原启用状态。

知识包可承载公式、词汇、快捷键等内容。制作 JSON 时参考 [格式说明](knowledge_pack_format.md) 和 [AI 制作模板](knowledge_pack_ai_template.md)。可直接导入三份进阶模板：[公式 · 微积分](../knowledge_packs/authoring_template.json)、[英语 · 进阶单词](../knowledge_packs/vocabulary_template.json)、[Rust · 常用写法](../knowledge_packs/rust_template.json)，每份 12 题；标签与名称按内容搭配，显示为「标签　名称」。

首次启动附带五个小包，每包四道题；内容是用途示例，可以自行编辑、删除或只开启其中几个。

| 领域与示例文件 | 提示示例 | 答案 |

## 图片题面

从 `0.2.0` 起，可以在题目编辑器中添加一张静态 PNG 或 JPEG 图片；`0.1.0` 不包含此功能。点击「添加图片」选择文件，也可将图片文件拖入正在编辑题目的主窗口。已有图片可以更换或移除，点击预览图可放大查看。保存提交整个题目，取消编辑保留原图片。

练习时沿用紧凑卡片，按短提示、图片、作答区排列。从 0.5.0 起支持将有图片的题面文字留空：填空、选择和知识展示只显示图片与作答区或答案，不保留文字占位；主窗口以带序号的「图片题」显示，仍可点击编辑。需要文字提示的图片题照常显示；判断题仍显示判断陈述。没有图片时必须填写题面。

图片保留原色、等比完整显示，支持填空、选择、判断与知识展示；点击图片可在独立窗口中放大，Esc 关闭放大窗口。查看大图时暂停卡片的自动收起，返回后可继续作答或手动收起；答错仍须按 Enter 确认。

图片导入后复制到 Try 数据目录的 `media/`，不依赖原文件位置。导入文件上限 8 MiB、1200 万像素，宽高均不超过 8192 像素；软件在后台按卡片需要缩小，显示用图最多 524288 像素。每个知识包最多使用 128 张不同图片、处理后合计 16 MiB。同一图片可以被多题共用，只有不再被任何题目或当前草稿引用时才会清理。

含图知识包仍导出为一个 JSON 文件，图片随包携带；换一台电脑导入也能使用。旧的纯文字／公式 JSON 继续兼容；带文字的含图包需要 Try 0.2.0 或更新版本，纯图题还需要支持空题面的版本。移动 Windows 便携版时请保留整个 `data/`，包括 `media/`。图片缺失或损坏会提示修复，不会作为一次错误作答。

## 公式输入

常见表达式如 `sin(pi/3)`、`sqrt(3)/2` 和支持的 LaTeX 可以直接输入，不需要先展开键盘。识别到公式结构后直接在排版中编辑；公式题中的分数、根号等未完成结构保留为草稿，提交时提示继续填写。普通文字保留原生输入与输入法。

作答框内可以点击分子、分母或指数定位，左右键移动，上下键切换排版行；Shift 配合方向键或拖动选择。公式复制粘贴使用支持的 LaTeX，普通文字保留原文；Ctrl+Z / Ctrl+Y 撤销和重做。识别用于书写和排版，不进行任意代数化简或近似数值判等。

光标在指数或下标内时，`+`、`-` 等运算符继续输入在该位置。要在外层继续输入，先在行末按右方向键，或点击 ↗。

ƒ 展开下方公式键盘，支持函数、符号、分数、根号、上下标、积分、求和、极限、矩阵和分段函数。练习作答始终使用同一个输入控件，ƒ 只开合键盘，保留未完成的公式、光标、选区和撤销记录。Enter 直接核对答案；未完成的公式继续提示补齐。键盘展开时 Esc 收起键盘，已收起时 Esc 关闭未作答题板。

题目编辑器中的 ƒ 仍用于编辑选中的公式内容；「应用公式」或 Enter 写回该字段，Esc 取消这次修改。普通文字和文字数学混排仍可在内容编辑器中编辑。

展开和收起时，卡片沿用所选角落或手动放置的位置；为避开屏幕边界的临时移动不会覆盖记忆位置。

「外移」「拆层」用于调整作用范围并保留内容。C 清空当前字段，撤销恢复清空前的草稿和位置；清空不提交答案。结构工具使用当前光标和选区，↑ 选择外层，↗ 在外层后继续输入；空模板可退出后再回来填写。

## 设置与暂停

左下角「设置」进入设置，旁边「关于」查看版本与更新。设置分为「练习」「卡片」「通用」，修改后自动保存，失败时保留此前有效数据。「通用」中的「外观」可以选择浅色、深色或跟随系统，默认跟随系统；主窗口内容、标题栏和练习卡片同步变化，重启后保留选择。已有明确保存的浅色／深色选择保持有效。同页「语言」可以选择跟随系统、简体中文或 English，知识包内容保持原语言。

「练习」中分别设置「答对后停留」与「知识展示停留」，两项互不影响；答错后仍须按 Enter 确认，不自动收起。提醒间隔提供 15、25、30、45 分钟，答对后停留提供 1、2、3 秒，知识展示停留提供 5、8、15、30 秒。旁边的精细配置图标可输入自定值，两项停留均支持 1 至 60 秒；Enter 应用，Esc 取消。已有用户的两项初始值均沿用原来的卡片停留时间，随后分别保存。

「暂离」按选定时长停止自动弹题；「暂停」持续到手动恢复。暂停状态重启后保留，「恢复」重新等待完整提醒间隔，不补发错过的题目。暂停和免打扰期间仍可手动开始一题，手动练习不会解除暂停。

「答题／知识展示」的选择也会自动保存，普通启动、登录自启和软件更新后沿用上次保存的方式。较早版本未保存过这项选择，首次升级按答题模式启动，重新选择后开始记忆。

每日免打扰与登录自启默认关闭。免打扰可跨午夜，默认时段 22:00 至次日 08:00；登录自启开启后直接进入托盘。Windows 卡片可选择工作区四角，拖动题面或空白处调整位置。

## 数据、更新与问题反馈

Windows 发布版首次运行在 exe 旁创建 `data/`，`state.json` 保存设置与知识包，`learning_state.json` 单独保存个人练习状态。已有数据首次更新没有历史时从未评估开始，知识展示不会创建学习文件；导出知识包不包含个人记录。Mac/Linux 默认使用系统应用数据目录，导入后同样不依赖原 JSON 路径。开发构建及独立数据目录参数见 [开发说明](development.md)。

从 `0.3.0` 起支持应用内更新。从 0.5.0 起，在关于页发现新版后，点击「下载并重启」开始下载，可查看进度或取消；下载与校验完成后自动退出、安装并重启，无需再次确认。开始前先保存或取消正在编辑的内容；下载期间新开的编辑或待确认导入会暂缓重启，保存或取消后自动继续，等待期间仍可取消更新。下载失败或校验不通过不会重启。Try 替换原位置的程序，并使用原数据目录重新启动，设置、知识包、图片和学习记录继续保留。新版完成数据读取与启动后才清理旧程序；替换或启动失败时尝试恢复旧版及配置备份，恢复失败则显示保留备份的位置。

点击下载后会先重新检查最新公开版本，再下载对应程序；本次检查不受每日自动检查间隔限制。检查与下载阶段均可取消，失败时可重试；检查失败不会继续安装此前缓存的旧版本。

`0.2.1` 及更早版本需手动升级一次：从托盘退出，保留 `data/` 并替换原位置的 `try.exe`。不要仅在另一个文件夹中打开新 exe，否则会使用那个文件夹的新数据。搬移便携版时将 exe 与 data 一起移动；开启过登录自启的程序搬移后，可在新位置关闭再开启登录自启，更新系统启动项。

关于入口为左下角 ⓘ，可查看版本、手动检查更新、打开项目主页和第三方声明；Esc 或点击面板外收起。完整版权与许可见 [许可说明](licensing.md)。

默认开启自动检查更新：启动后至少等待 30 秒，每 24 小时最多自动检查一次，重启不会重复检查。有新版时在关于图标显示红点，详情在关于页查看，不另弹通知；只有主动点击「下载并重启」后才开始下载并在完成后重启。设置「通用」中的「自动检查更新」可关闭，手动检查始终可用。检查时间与最近成功结果保存在同一数据目录的 `update_check_state.json`。

问题与建议请提交到 [Issues](https://github.com/Ethan-decoy/Try/issues)。
