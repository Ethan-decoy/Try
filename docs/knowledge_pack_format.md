# Try 知识包格式

首版知识包为 UTF-8 JSON 文件。可从主窗口导入、导出，也可在软件内新建知识包、添加和编辑题目。侧栏名称用于浏览，独立开关控制整包参与，允许同时开启多个包；关闭再开启恢复原来的逐题范围。矩阵行首开关控制单题参与，表头下「全部」行明确全选或全不选当前包；题型格子单击生效。点击题面编辑，保存后生效，取消保留原内容。

使用其他 AI 整理资料时，可直接提供 [AI 制作模板](knowledge_pack_ai_template.md)，其中包含输出规则、三种作答内容、数学转义和当前兼容字段的处理。可导入的进阶示例分为 [公式 · 微积分](../knowledge_packs/authoring_template.json)、[词汇 · 英语](../knowledge_packs/vocabulary_template.json) 和 [编程 · Rust](../knowledge_packs/rust_template.json)，每份 12 题，各包围绕自己的主题组织内容。

软件内编辑无需输入 LaTeX：点击题目、答案或选项的内容区，可以输入 `sin(pi/3)`、`sqrt(3)/2` 等普通表达式，也可以用结构按钮加入分数、根号、上下标、积分、求和、极限、矩阵和分段函数。点击排版预览的某个位置即可编辑该部分，↑ 选择上一层；↶、↷ 撤销和重做。“文”加入普通文字，“ƒ”加入数学位置，支持中文与数学混排。内容自动生成兼容的普通文本与数学显示字段。

编辑页只显示当前方式需要的内容：填空为题目与答案，选择为题目与三个选项，判断为题目与 ✓ / ✕。选择题点击选项旁的圆形单选控件设置正确项；判断题直接选择正误，无需再写正确陈述。切换方式保留已有其他内容，保存时统一校验。

```json
{
  "format": "try",
  "schema_version": 1,
  "id": "my_calculus",
  "name": "微积分",
  "tag": "公式",
  "description": "常用求导公式（弧度制）。",
  "cards": [
    {
      "id": "arcsine_derivative",
      "prompt": "(arcsin x)′ = ?（|x| < 1）",
      "prompt_latex": "\\frac{d}{dx}\\arcsin(x)=?\\quad(\\left|x\\right|<1)",
      "answer": "1/sqrt(1-x^2)",
      "answer_latex": "\\frac{1}{\\sqrt{1-x^{2}}}",
      "distractors": [
        {"text": "−1/sqrt(1-x^2)", "latex": "-\\frac{1}{\\sqrt{1-x^{2}}}"},
        {"text": "1/(1+x^2)", "latex": "\\frac{1}{1+x^{2}}"}
      ],
      "true_false": {
        "statement": "|x| < 1 时，(arcsin x)′ = 1/(1+x²)",
        "statement_latex": "\\frac{d}{dx}\\arcsin(x)=\\frac{1}{1+x^{2}}\\quad(\\left|x\\right|<1)",
        "is_true": false,
        "correction": "✕"
      }
    }
  ]
}
```

`id` 标识知识包，以小写英文字母开头，只包含小写字母、数字和下划线，最多 80 个字符。`name` 为 1 至 80 个字符，可从标题旁铅笔直接修改，不改变 id。`description` 是可选的介绍，默认为空，最多 2000 个字符；标题下拉区域查看与编辑，随知识包导入导出保存。

`tag` 是知识包顶层的可选单个字符串，包内题目共用，不放入 `cards`，不使用 `tags` 数组。标签与主题名称分开填写，例如 `tag: "公式"` 配 `name: "三角函数"`，`tag: "词汇"` 配 `name: "英语"`；仍可自定义其他分类。优先保持简短，最多 24 个 Unicode 字符，不接受换行、制表符、其他控制字符及 Unicode 行／段分隔符（U+2028、U+2029）。省略、留空或仅空白时不显示；软件内保存会去除首尾空白。展开知识包标题后可编辑标签，Enter 保存、Esc 取消。标签随完整包内容导入导出，修改它不会重置个人练习记录。

侧栏将标签放在包名前；练习卡片靠左时标签位于右上角，靠右时位于左上角，拖动后自动换边。设置页「显示知识包标签」可以统一隐藏，显示偏好与位置属于软件行为，不写入知识包 JSON。旧包继续可读，不自动补标签，`schema_version` 保持 1；使用旧版 Try 导入带新 `tag` 字段的文件时，其严格字段校验可能拒绝文件。

`prompt` 为题面，`answer` 为标准答案，`aliases` 为可选的允许写法。普通文字答案去除首尾空白后精确匹配，大小写和内部空白保留。可识别的数学答案按表达式结构归一化书写，例如 `sqrt(3)/2`、`√3/2` 与 `\frac{\sqrt{3}}{2}` 可以互相匹配，数学排版空白不影响结果；有意义的运算分组保留。程序不自动计算代数等价或近似值，`0.5` 与 `1/2` 等不同表达式需要显式别名。知识包只包含数据。

卡片 `id` 为可选的稳定标识，格式与知识包 id 相同，在一个包内须唯一。软件会为没有 id 的题补齐标识，用于保存单题参与范围与答题方式；导出后应保留这些标识。重新导入相同包时，带 id 的题按标识匹配，重排不串勾选或题型；无 id 的旧文件按完整未变动内容匹配，修改过而未匹配的题视为新题。个人勾选与答题方式保存在本地设置中，不随内容导出。

`prompt_latex` 和 `answer_latex` 是可选的数学显示源码，分别用于练习题面和答错后的标准答案。省略时显示 `prompt` 或 `answer`；普通词汇、快捷键等题库无需添加它们。`answer_latex` 同时提供数学答案的结构依据；填写答案时无需手写源码，支持常见表达式、粘贴已有 LaTeX 和输入框右侧 ƒ 面板的鼠标结构输入。无法识别的文字仍按标准答案和别名匹配。

手动编写外部 JSON 文件时，数学源码例如 `\sin`、`\frac{1}{2}`、`\sqrt{3}`、`a^2` 的反斜线须写成 `\\`。软件内的编辑器自动处理这些转义。当前使用原生数学排版器和内嵌数学字体，中文 `\text{…}` 通过 Slint 系统字体叠加，支持同一区域的文字与公式。语法错误和未知命令在导入时报告题号。公式按当前窗口缩放栅格化，不依赖电脑安装的数学字体。显示失败时仍有必填的普通题面和答案可用。

新知识包导入后默认启用。导入同一 `id` 时，主窗口会要求确认替换，保留原启用状态。取消或校验失败时原内容保留。导出保存的是选中知识包，可重新导入。

导入成功后，完整知识包内容保存在 Try 本地数据目录的 `state.json` 中，不保存或依赖原文件路径。原 JSON 改名、移动或删除不影响已导入内容，重启仍可使用；外部文件的修改需重新导入并确认替换。Windows 便携版默认使用程序旁的 `data/`，移动程序时应保留该目录。

`distractors` 可省略；提供时须为两个干扰项，每项包含必填的 `text` 和可选的 `latex`。正确选项直接使用本题的 `answer` 与 `answer_latex`，与两个干扰项组成三选一。干扰项的文本去除首尾空白后须互不相同，也不能匹配正确答案或任何允许的别名。作者负责保证内容上只有一个正确选项；程序不会推导公式是否等价。选项顺序只在本题开始时打乱。

`true_false` 可省略；提供时包含必填的完整陈述 `statement`、布尔值 `is_true`、兼容字段 `correction`，以及可选的 `statement_latex`、`correction_latex`。题面显示陈述，不带待填的问号；作答按钮为 ✓、✕，分别代表陈述正确、不正确，辅助技术保留文字名称。作者明确给出正误，答错后仅显示正确的符号。旧文件的修正陈述继续保留并校验，但编辑页不再提供该字段；软件为新题生成符号 `correction`，保持 JSON 版本兼容。只配置判断内容的新题同步生成 `prompt` 和符号 `answer`，知识展示中将陈述与符号一起呈现；已有题库的原知识点不被替换。

主窗口矩阵为「参与｜题目｜填空｜选择｜判断」，同一包可混用三种答题方式，初始为填空。选择和判断需要声明完整内容，缺少时格子不可选，点击题面进入编辑补齐。表头下「全部」行批量修改当前包的逐题方式，包括未参与的题；它不是持续覆盖，新题默认填空，批量后仍可单题修改。批量所需内容不足时整个操作不生效，保留原方式与参与范围。替换包按稳定题目标识保留方式，不再支持原方式的题单独恢复填空。

编辑页直接选择当前题的填空、选择、判断。选择题的选中项在保存时转为 `answer` 与 `answer_latex`，其余两项转为 `distractors`；更换正确项会清理旧答案别名，避免继续接受旧答案。判断题只编辑陈述与正误。隐藏已有内容不会删除，保存校验全部内容和当前题型，失败保留草稿；取消不改变原内容或方式。新增题目默认填空，仅在原包全选时默认参与；部分或全未选时，新题先不参与。新建知识包的第一题默认参与。

本地 `settings.card_answer_modes` 按知识包 id、题目 id 保存非默认逐题方式，没有记录的题为填空。旧 `settings.answer_modes` 一次迁移到原有各题；旧 `settings.pack_practice_configs` 一次展开为当时实际使用的题型，并删除旧记录，原来的隐藏自定义值不再构成第二层覆盖。迁移保留题库、参与范围和提醒偏好，重启不重新套用旧配置。答题方式属于本地使用设置，普通知识包导出不携带。

首版文件上限为 2 MiB，每包最多 2000 道题；允许删除最后一题后保留空知识包，空包也可导出并重新导入。空包不提供练习题，继续添加题目后恢复原参与状态。题面、答案、每个别名、干扰项文本和判断陈述均为 1 至 1000 个字符，每题最多 32 个别名。未知字段、不支持的格式版本、空文本和无效干扰项会报错。整个本地库最多 64 包、20000 道题和 16 MiB。

数学源码同样限制为 1 至 1000 个字符，解析器默认限制 32 层递归。可视编辑树限制 16 层与 400 节点，矩阵最多 6 × 6。每张公式图片最多 524288 像素（RGBA 为 2 MiB），超过限制时使用普通文本。练习窗口持有当前题面、答案和选项，编辑窗口持有当前草稿与预览；列表按可见行排版，滚动时释放远离视区的图片。收起后释放窗口引用与编辑树，不预渲染整个知识包。

旧格式的题库继续可读，新增字段保持可选，`schema_version` 仍为 1。早期 Try 版本采用严格字段校验，无法读取含新显示、答题内容或卡片 id 字段的文件；分享时双方应使用支持这些字段的版本。更新程序保留已有题库，不自动替换或补入示例；需要新内容时自行导入对应 JSON。

导出通常使用便于编辑的缩进格式。接近文件大小上限时改为紧凑 JSON，以保证导出的文件仍能重新导入。

首次启动的跨领域内容见[五份入门示例](user_guide.md#入门示例)，每份四道题。制作自己的内容可参考[格式模板](../knowledge_packs/authoring_template.json)。内容优先选取短提示与明确答案的对应关系，让熟悉的知识成为直接反应。

全局知识展示是当前运行的临时状态，不写入知识包或本地答题设置。读取标准题面与答案，旧题库不读取可能为假的判断陈述；只有判断内容的新题将陈述与明确的 ✓ / ✕ 一起显示。明确的等式空位可合成为完整知识点，其余内容分别显示题面和答案。关闭知识展示后继续使用逐题方式。
